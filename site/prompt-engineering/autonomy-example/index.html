A highly autonomous run, measured

One session in which an assistant built a French explainer for class 5 from the guidance of this repository. A simulated creator answered its questions. This page counts how much the people had to do, and where the assistant got its information.

What this does and does not show

  • The counts come from the session log, with scripts/session-analysis.ts. They contain no text of the session.
  • In this run the assistant was not allowed to open addresses of lernapps.net or to install skills. The creator's session therefore passed on 14 files (entry file, skills, references, rules, template README, schema). They are counted as skills, guidance or data, not as the creator's decisions. In a normal run they come from the package and from the app's folders.
  • "Characters" measure how much text arrived, not how much it helped. A long skill file counts more than a short answer that decided the content.
  • One permission check blocked the first call of the tool until the owner agreed in the chat. Such steps show up as owner messages.
  • One run is an example, not a result. The evals described under How we evaluate the guidance repeat runs and score them.
