A highly autonomous run, measured

One session in which an assistant built a French explainer for class 5 from the guidance of this repository. A simulated creator answered its questions and later asked for a review, changes and measurements. This page counts how much the creator had to say, where the assistant got its information, and what the reviews and checks of the run found.

  • Learner check of the pattern page (before the creator saw it): the sub-agent used page 1 as a child of class 5 and found about a dozen places where a learner gets stuck: unexplained words (Artikel, Voilà, Vokal), a figure whose markers hid the objects, missing error messages. All were fixed before the page was shown.
  • Review of the committed app (review/prompt.md with the rubric, no listing pull request): verdict pass with 0 errors, 2 warnings and 6 hints (one warning is a proposed new rule). The findings the checks had not decided: a scope that named a date the page did not use, wrong "last page" references, an article rule that later pages broke, numbers 21 to 69 missing under the title "0 à 100", a licence question, and 4888 files of node_modules/ that had been committed. It did not notice that the two story children were nowhere in the drawings.
  • Walkthrough of the whole app as a child of class 5, from the start page to the last page: it found where pages did not fit together. A calendar showed Saturday while the text said Monday, three pages named the wrong page before them, a picture showed a book where the text said a pencil case, words were asked before they were taught (salut, le français, 0, 21 to 69), and the story jumped between places. Most were fixed in one commit.

lernapps check passed on the final state of each step and flagged none of these. The review and the learner checks found what the program could not decide: whether the pages fit together for a child.

What this does and does not show

  • The counts come from the session log, with scripts/session-analysis.ts. They contain no text of the session.
  • The creator's session passed on 14 files (entry file, skills, references, rules, template README, schema). They are counted as skills, guidance or data, not as the creator's decisions. The creator's own messages are counted as answers (to the assistant's questions) or tasks (a review, changes to the app, measurements).
  • "Characters" measure how much text arrived, not how much it helped. A long skill file counts more than a short answer that decided the content.
  • Results of tools named with --leave-out (by default the Artifact tool, whose built-in guidance decides nothing) are not counted. The text of the tool that attaches a repository is counted as GitHub retrieval.
  • Time is active time: a wait of more than 15 minutes between two entries of the log counts as one minute.
  • In this run the assistant was not allowed to open addresses of lernapps.net or to install skills. That is why the creator's session passed on the files. In a normal run they come from the package and from the app's folders.
  • The session waited overnight between the first work and the reviews.
  • One run is an example, not a result. The evals described under How we evaluate the guidance repeat runs and score them.
