Rules

Each rule is one requirement on a learning app. It lives where it acts: as a section of a skill for AI assistants, as a check, as a lint rule or as an item of the review rubric. The same rule can live in several of them, always under the same id. This page reads them from there.

  • Scope: listing applies to every app in the app overview, wherever it is hosted; site to every page on lernapps.net; archetype:… to apps of that archetype.
  • Severity: error must not be broken; warning only with a reason recorded in place; hint is a recommendation.

Every message of a check links to its rule here, by its id: https://lernapps.net/tooling/rules/#<id>.

Accessible to WCAG 2.1 AA

accessible · listing, site · error

Meet WCAG 2.1 AA: labels, contrast, keyboard use, text alternatives.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/accessible.ts.

Run the checks before you push

checks-pass · listing · error

Run lernapps check before you push; the hooks run it too. Format, lint, type check, unit tests, build, the checks of the built app and the end-to-end tests must pass. A failure names the step: fix it from the step's output.

Told in the skill skills/lernapps-app/SKILL.md.

Only dependencies with an open licence

dependency-licence · listing · error

Add a package to dependencies only if it and its own dependencies have one of these licences: MIT, MIT-0, ISC, 0BSD, BSD-2-Clause, BSD-3-Clause, Apache-2.0, MPL-2.0, BlueOak-1.0.0, Zlib, Unlicense, CC0-1.0, CC-BY-4.0, Python-2.0. Tools for the build belong in devDependencies.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/dependency-licence.ts.

Fitness values as measured

entry-fitness-matches · listing · error

Take fitness.storage and fitness.thirdParty from what the app does, not from what it should do: lernapps check --report <file> measures what it does before a click. An app that keeps anything in localStorage has storage: device; one that loads from another server after a click has thirdParty: on-click.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/entry-fitness-matches.ts.

Fill the entry from the published schema

entry-from-schema · listing · error

Fetch the entry schema each time you need it; never fill the entry from memory or from another app. Take every value from the creator's answers, the plan or the app; never invent one.

Told in the skill skills/lernapps-app/SKILL.md.

Every link of the entry resolves

entry-links-resolve · listing · error

Give each topic the path of a page that exists, relative to the app's url. Check the entry against the deployed app with lernapps check --entry <file>.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/entry-links-resolve.ts.

No code before the plan is confirmed

explore-before-code · listing · error

Write no code and generate nothing until the creator has confirmed the plan.

Told in the skill skills/lernapps-app/SKILL.md.

Work on your own after the plan

few-turns-after-plan · listing · hint

After the plan is confirmed, ask the creator only what you cannot decide. Otherwise choose, mark it "(guess)" under "Key decisions" and list it in the retrospective.

Told in the skill skills/lernapps-app/SKILL.md.

Fix failed checks, never bypass them

fix-from-message · listing · error

Read the message of a failed check and fix the cause. Never bypass a hook (--no-verify), never delete a test to make it pass. Suppress a warning only where it occurs, with the reason next to it.

Told in the skill skills/lernapps-app/SKILL.md.

Free of charge

free-of-charge · listing · error

Every part of the app is free: no payment, no paid upgrade, no trial that ends.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

German, plain language for learners

learner-text-german · listing · error

Write every text for learners, teachers and parents in German, in plain language: short sentences, active voice, no jargon. Keep the texts in message files, not in code.

Told in the skill skills/lernapps-app/SKILL.md.

Learners do something themselves

learners-act · listing · error

Learners try, practise or decide in the app; reading alone is not enough. Each page or screen asks them to act.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

Every link resolves

links-resolve · listing, site · error

Point every link and every resource (pictures, scripts, styles) to a page or file that the build writes. Use relative links inside the app.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/links-resolve.ts.

No account

no-account · listing · error

Learners and teachers use the whole app without signing up or logging in.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

No ads

no-ads · listing · error

Show no advertising, no sponsored content, no product placement.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

No request to another server before a click

no-request-before-click · listing, site · error

Bundle fonts, scripts and pictures at build time. Load anything from another server (a video, a map) only after the learner clicks for it.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/no-request-before-click.ts.

Collect nothing, set no cookies

no-tracking · listing, site · error

No cookies, no analytics, no tracking pixels, no server that stores data. If the app stores anything, it stays on the device (localStorage) and serves only the app.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/no-tracking.ts.

Keep the plan file

plan-file · listing · error

Keep .vibe/plan.md from the template, with every section and front matter key. Update phase when you enter a phase. Never edit prePushFailures: the pre-push hook writes it.

Told in the skill skills/lernapps-app/SKILL.md.

Fill the retrospective

retrospective-filled · listing · error

At the end of Commit, fill every part of the retrospective with facts: phases reached, failed checks with rule ids, the creator's turns after the plan, where you had to guess. No names of people.

Told in the skill skills/lernapps-app/SKILL.md.

Runs in the browser, without installation

runs-in-browser · listing · error

The app opens at its URL in a current browser and works there. Nothing to install: no app store, no download, no browser extension.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

Stop at the creator's checkpoints

stop-at-checkpoints · listing · error

Stop at each checkpoint (confirm the plan, publish, list) and wait for the creator's answer. Example: "Die App ist fertig und geprüft. Soll ich sie jetzt veröffentlichen?"

Told in the skill skills/lernapps-app/SKILL.md.

Name source and licence of others' content

third-party-licence · listing · error

Use content of others (texts, pictures, quotes) only with a licence that allows it, and name source and licence next to it.

Told in the skill skills/lernapps-app/SKILL.md.

Usable at 360 px

usable-at-360px · listing, site · error

Every page works at 360 px width without horizontal scrolling, with every control reachable.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/usable-at-360px.ts.

Link imprint and privacy notice

imprint-and-privacy · site · error

Every page links to https://lernapps.net/imprint/ and https://lernapps.net/privacy/.

Told in the skill skills/lernapps-app/SKILL.md.

Readable without JavaScript

readable-without-javascript · site · error

Every page says what it is and what the app does without JavaScript. The skill of the archetype says how much more.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/readable-without-javascript.ts.

site-check
