Rules

Each rule is one requirement on a learning app. It lives where it acts: as a section of a skill for AI assistants, as a check, as a lint rule or as an item of the review rubric. The same rule can live in several of them, always under the same id. This page reads them from there.

  • Scope: listing applies to every app in the app overview, wherever it is hosted; site to every page on lernapps.net; archetype:… to apps of that archetype.
  • Severity: error must not be broken; warning only with a reason recorded in place; hint is a recommendation.

Every message of a check links to its rule here, by its id: https://lernapps.net/tooling/rules/#<id>.

Accessible to WCAG 2.1 AA

accessible · listing, site · error

Meet WCAG 2.1 AA: labels, contrast, keyboard use, text alternatives.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/accessible.ts.

Run the checks before you push

checks-pass · listing · error

Run lernapps check before you push; the hooks run it too. Format, lint, type check, unit tests, build, the checks of the built app and the end-to-end tests must pass. A failure names the step: fix it from the step's output.

Told in the skill skills/lernapps-app/SKILL.md.

Help keep the content correct

correct-content-support · listing · hint

Where answers are computable, generate the exercises and test the answers with a checker. Name a source learners and teachers can follow for facts. This should be done where it fits; it is never a condition for listing.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

Only dependencies with an open licence

dependency-licence · listing · error

Add a package to dependencies only if it and its own dependencies have one of these licences: MIT, MIT-0, ISC, 0BSD, BSD-2-Clause, BSD-3-Clause, Apache-2.0, MPL-2.0, BlueOak-1.0.0, Zlib, Unlicense, CC0-1.0, CC-BY-4.0, Python-2.0. Tools for the build belong in devDependencies.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/dependency-licence.ts.

Fitness values as measured

entry-fitness-matches · listing · error

Take fitness.storage and fitness.thirdParty from what the app does, not from what it should do: lernapps check --report <file> measures what it does before a click. An app that keeps anything in localStorage has storage: device; one that loads from another server after a click has thirdParty: on-click.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/entry-fitness-matches.ts.

Fill the entry from the published schema

entry-from-schema · listing · error

Fetch the entry schema each time you need it; never fill the entry from memory or from another app. Take every value from the creator's answers, the plan or the app; never invent one.

Told in the skill skills/lernapps-app/SKILL.md.

Every link of the entry resolves

entry-links-resolve · listing · error

Give each topic the path of a page that exists, relative to the app's url. Check the entry against the deployed app with lernapps check --entry <file>.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/entry-links-resolve.ts.

No code before the plan is confirmed

explore-before-code · listing · error

Write no code and generate nothing until the creator has confirmed the plan.

Told in the skill skills/lernapps-app/SKILL.md.

Work on your own after the plan

few-turns-after-plan · listing · hint

After the plan is confirmed, ask the creator only what you cannot decide. Otherwise choose, mark it "(guess)" under "Key decisions" and list it in the retrospective.

Told in the skill skills/lernapps-app/SKILL.md.

Fix failed checks, never bypass them

fix-from-message · listing · error

Read the message of a failed check and fix the cause. Never bypass a hook (--no-verify), never delete a test to make it pass.

Told in the skill skills/lernapps-app/SKILL.md.

Free of charge

free-of-charge · listing · error

Every part of the app is free: no payment, no paid upgrade, no trial that ends.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

German, plain language for learners

learner-text-german · listing · error

Write every text for learners, teachers and parents in German, in plain language: short sentences, active voice, no jargon. Keep the texts in message files, not in code: in an app from an archetype, in src/messages/de.json, shown with translator from @lernapps/tooling/i18n.

Told in the skill skills/lernapps-app/SKILL.md; checked by the lint rule lint/rules/learner-text-german.ts; judged by the rubric item in review/rubric.md.

Learners do something themselves

learners-act · listing · error

Learners try, practise or decide in the app; reading alone is not enough. Each page or screen asks them to act.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

Every link resolves

links-resolve · listing, site · error

Point every link and every resource (pictures, scripts, styles) to a page or file that the build writes. Use relative links inside the app.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/links-resolve.ts.

No account

no-account · listing · error

Learners and teachers use the whole app without signing up or logging in.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

No ads

no-ads · listing · error

Show no advertising, no sponsored content, no product placement.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

Nothing about a particular learner in public texts

no-learner-data-in-texts · listing · error

Write no name, class, school, grade, picture or other detail of a real learner into the app, the entry, the README, the plan or a commit message, even when the creator mentions one. Use made-up names in exercises.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

No request to another server before a click

no-request-before-click · listing, site · error

Bundle fonts, scripts and pictures at build time. Load anything from another server (a video, a map) only after the learner clicks for it. Keep URLs of other servers out of code; where the learner clicks to load one, suppress the lint message on that line with this reason.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/no-request-before-click.ts; checked by the lint rule lint/rules/no-request-before-click.ts.

Collect nothing, set no cookies

no-tracking · listing, site · error

No cookies, no analytics, no tracking pixels, no server that stores data. If the app stores anything, it stays on the device (localStorage) and serves only the app.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/no-tracking.ts; judged by the rubric item in review/rubric.md.

Keep the plan file

plan-file · listing · error

Keep .vibe/plan.md from the template, with every section and front matter key. Update phase when you enter a phase. Never edit prePushFailures: the pre-push hook writes it.

Told in the skill skills/lernapps-app/SKILL.md.

Fill the retrospective

retrospective-filled · listing · error

At the end of Commit, fill every part of the retrospective with facts: phases reached, failed checks with rule ids, the creator's turns after the plan, where you had to guess. No names of people.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

Runs in the browser, without installation

runs-in-browser · listing · error

The app opens at its URL in a current browser and works there. Nothing to install: no app store, no download, no browser extension.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

Stop at the creator's checkpoints

stop-at-checkpoints · listing · error

Stop at each checkpoint (confirm the plan, publish, list) and wait for the creator's answer. Example: "Die App ist fertig und geprüft. Soll ich sie jetzt veröffentlichen?"

Told in the skill skills/lernapps-app/SKILL.md.

Suppress only in place, with the reason

suppression-reason · listing · error

Suppress a lint message only on the line where it occurs, name the rule and write why after --: // oxlint-disable-next-line lernapps/no-request-before-click -- the video loads after a click. Suppress a type error only with // @ts-expect-error -- <reason>, never with @ts-ignore or @ts-nocheck. The review reads every suppression.

Told in the skill skills/lernapps-app/SKILL.md; checked by the lint rule lint/rules/suppression-reason.ts.

Name source and licence of others' content

third-party-licence · listing · error

Use content of others (texts, pictures, quotes) only with a licence that allows it, and name source and licence next to it.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/rubric.md.

Usable at 360 px

usable-at-360px · listing, site · error

Every page works at 360 px width without horizontal scrolling, with every control reachable.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/usable-at-360px.ts.

Link imprint and privacy notice

imprint-and-privacy · site · error

Every page links to https://lernapps.net/imprint/ and https://lernapps.net/privacy/.

Told in the skill skills/lernapps-app/SKILL.md.

Readable without JavaScript

readable-without-javascript · site · error

Every page says what it is and what the app does without JavaScript. The skill of the archetype says how much more.

Told in the skill skills/lernapps-app/SKILL.md; checked by the check check/rules/readable-without-javascript.ts.

Extend the preset, change nothing of it

keep-the-preset · archetype:explainer, archetype:interactive, archetype:quiz · error

An app from an archetype extends the preset of @lernapps/tooling and configures nothing the preset sets: vite.config.ts is export default lernapps(), tsconfig.json only extends @lernapps/tooling/tsconfig.json, the hooks come from the package (prepare in package.json). Pass only the app's own settings to lernapps({ ... }), such as the pages to build or the build step of its archetype's runtime, as generated: lernapps({ plugins: [quiz()] }). Never turn a lint rule off or lower its severity, never replace a hook.

Told in the skill skills/lernapps-app/SKILL.md.

Check every fact

quiz-answers-checked · archetype:quiz · hint

Check every marked option, every number and every info against the linked article before you commit. Where you cannot open a source, say so in the plan and mark the fact as not checked; never fill a gap from memory. Learners report errors through the issue form the generator wrote (.github/ISSUE_TEMPLATE/inhaltsfehler.yml).

Told in the skill skills/lernapps-quiz/SKILL.md.

The question bank validates

quiz-bank-valid · archetype:quiz · error

The bank validates against its schema. The build also checks what the schema cannot say: - exactly one correct option in a single choice, at least one in a multiple choice; - ids and options that appear only once.

A broken bank fails the build with one line per problem, naming the question by its position and id. Fix each one in src/quiz.json.

Told in the skill skills/lernapps-quiz/SKILL.md.

One clear question at a time

quiz-clear-question · archetype:quiz · warning

Ask one thing per question, complete in itself: the learner knows what to answer before reading the options. Ask positively; avoid "nicht" in the question, and never two negations. No trick questions: ask what is worth knowing, not whether the learner reads carefully. Plain German, short sentences (learner-text-german).

Told in the skill skills/lernapps-quiz/SKILL.md.

Background and explanation say why

quiz-feedback-explains · archetype:quiz · hint

Give every option an info of one to three sentences about the option itself. It must be true whether or not the option is the right answer, so that a learner who chose it learns something real. Example: "Der Nil fließt durch mehrere Länder Afrikas und mündet in Ägypten ins Mittelmeer." The explanation says in one to three sentences why the right answer is right. For true/false, number, ordering and matching it also carries the background.

Told in the skill skills/lernapps-quiz/SKILL.md; judged by the rubric item in review/archetypes/quiz.md.

The type that fits the question

quiz-fitting-type · archetype:quiz · hint

Choose the type from what the learner should do: - recall one fact out of several things of the same kind: single-choice; - several facts: multiple-choice; - estimate a size: number; - compare sizes or dates: ordering; - connect things that belong together: matching; - judge a statement: true-false.

Mix types across the quiz.

Told in the skill skills/lernapps-quiz/SKILL.md.

Every question links to further reading

quiz-further-reading · archetype:quiz · warning

Link every question to at least one page where learners read on, best the article in the German Wikipedia (https://de.wikipedia.org/wiki/...). Open every link before you commit: - it answers without an error; - it is the article you mean, not a disambiguation page ("Begriffsklärung"); - it says what your question and options say.

Name the page in the link's title, e.g. "Uluru (Wikipedia)". Never guess an address.

Told in the skill skills/lernapps-quiz/SKILL.md.

Numbers with unit and rounding

quiz-number-precision · archetype:quiz · warning

A number question says in its text how exactly to answer, e.g. "Bis zu 100 m daneben zählt noch als richtig". It names the unit in unit, not in the learner's answer. Match tolerance to what the text says. Where sources differ (the height of a mountain), choose a tolerance that covers them.

Told in the skill skills/lernapps-quiz/SKILL.md.

Write only the question bank

quiz-only-data · archetype:quiz · error

Change src/quiz.json and nothing of the quiz's code. Keep index.html, src/main.ts, e2e/quiz.e2e.ts and the configuration as generated (keep-the-preset). If the quiz needs something the bank cannot say, write it under "Where I had to guess" in the retrospective instead of coding around the runtime.

Told in the skill skills/lernapps-quiz/SKILL.md.

Write in your own words

quiz-own-words · archetype:quiz · warning

Take facts from your sources, never their sentences. Wikipedia's texts are under CC BY-SA, so a copied sentence needs attribution and puts the app's texts under the same licence. Write each info and explanation new, shorter and plainer than the source, for learners of the school year the app is for. Facts themselves are free to use; name where they come from in sources (third-party-licence).

Told in the skill skills/lernapps-quiz/SKILL.md.

Options a learner could believe

quiz-plausible-options · archetype:quiz · warning

Make every wrong option a real thing of the same kind as the right one: a river for a river, a mountain for a mountain. A learner could mix it up, and it has true background of its own. Make all options alike in length and form, so that the right one does not stand out. No "Alle genannten" or "Keine davon", no joke options. Three or four options are enough.

Told in the skill skills/lernapps-quiz/SKILL.md.

Keep the ids

quiz-stable-ids · archetype:quiz · warning

Give each question a short, telling id ("grand-canyon") and keep it when you change the text: teachers share links to single questions (#frage-<id>). Give a new question a new id; never reuse the id of a removed one.

Told in the skill skills/lernapps-quiz/SKILL.md.

site-check

site-check

The bundle of an app on lernapps.net passes lernapps-check of the site frame.

Checked by the check check/rules/site-check.ts.

The start page explains the app (interactive)

start-page-explains · archetype:interactive · hint

Say on the static start page what learners train, for whom, and how to begin. In the app page's <noscript>, say that the app needs JavaScript and what it does.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/archetypes/interactive.md.

Store only through the preset's storage

storage-through-wrapper · archetype:explainer, archetype:interactive, archetype:quiz · error

Keep what the app must remember with createStorage from @lernapps/tooling/storage, named after the app: it stays on the device, under the app's own prefix, and the app keeps working when the browser blocks storage. Never use localStorage, sessionStorage, IndexedDB or cookies directly.

Told in the skill skills/lernapps-app/SKILL.md; checked by the lint rule lint/rules/storage-through-wrapper.ts.

TypeScript only, strict

strict-typescript · archetype:explainer, archetype:interactive, archetype:quiz · error

Write every source in TypeScript; no JavaScript files. Never use any: use unknown and narrow it, or write the type. Type the data the creator supplies and validate it at build time.

Told in the skill skills/lernapps-app/SKILL.md.

Every topic has exercises (explainer)

topic-has-exercises · archetype:explainer · hint

Give every topic page exercises that practise what it explains, on the page or one link away, each with a solution or feedback learners can check.

Told in the skill skills/lernapps-app/SKILL.md; judged by the rubric item in review/archetypes/explainer.md.
