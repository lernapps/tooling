      2/5 entsteht, wenn man Zähler und Nenner addiert. Die Teile sind dann nicht gleich groß.

    • 1/2 + 1/3 = 2/6

    • 1/2 + 1/3 = 3/5

    Ungleichnamige Brüche erst gleichnamig machen: 1/2 = 3/6, 1/3 = 2/6. Dann 3 + 2 = 5, also 5/6.
