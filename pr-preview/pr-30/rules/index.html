Regeln

Jede Regel ist eine Anforderung an eine Lern-App. Sie steht dort, wo sie wirkt: als Abschnitt eines Skills für KI-Assistenten, als Prüfung, als Lint-Regel oder als Punkt der Begutachtung. Dieselbe Regel kann an mehreren Stellen stehen, immer mit derselben Kennung. Diese Seite liest sie von dort. Die Regeln selbst sind englisch, weil KI-Assistenten sie so lesen.

  • Geltung: listing gilt für jede App in der App-Übersicht, egal wo sie liegt; site für jede Seite auf lernapps.net; archetype:… für Apps dieser Art.
  • Schwere: error darf nicht verletzt werden; warning nur mit Begründung an Ort und Stelle; hint ist eine Empfehlung.

Jede Meldung einer Prüfung verlinkt auf ihre Regel hier, über deren Kennung: https://lernapps.net/tooling/rules/#<Kennung>.

Accessible to WCAG 2.1 AA

accessible · listing, site · error

Meet WCAG 2.1 AA: labels, contrast, keyboard use, text alternatives.

Fill the entry from the published schema

entry-from-schema · listing · error

Fetch the entry schema each time you need it; never fill the entry from memory or from another app. Take every value from the creator's answers, the plan or the app; never invent one.

Erklärt im Skill skills/lernapps-app/SKILL.md.

No code before the plan is confirmed

explore-before-code · listing · error

Write no code and generate nothing until the creator has confirmed the plan.

Erklärt im Skill skills/lernapps-app/SKILL.md.

Work on your own after the plan

few-turns-after-plan · listing · hint

After the plan is confirmed, ask the creator only what you cannot decide. Otherwise choose, mark it "(guess)" under "Key decisions" and list it in the retrospective.

Erklärt im Skill skills/lernapps-app/SKILL.md.

Fix failed checks, never bypass them

fix-from-message · listing · error

Read the message of a failed check and fix the cause. Never bypass a hook (--no-verify), never delete a test to make it pass. Suppress a warning only where it occurs, with the reason next to it.

Erklärt im Skill skills/lernapps-app/SKILL.md.

Free of charge

free-of-charge · listing · error

Every part of the app is free: no payment, no paid upgrade, no trial that ends.

Erklärt im Skill skills/lernapps-app/SKILL.md; beurteilt nach dem Punkt der Begutachtung in review/rubric.md.

German, plain language for learners

learner-text-german · listing · error

Write every text for learners, teachers and parents in German, in plain language: short sentences, active voice, no jargon. Keep the texts in message files, not in code.

Erklärt im Skill skills/lernapps-app/SKILL.md.

Learners do something themselves

learners-act · listing · error

Learners try, practise or decide in the app; reading alone is not enough. Each page or screen asks them to act.

No account

no-account · listing · error

Learners and teachers use the whole app without signing up or logging in.

No ads

no-ads · listing · error

Show no advertising, no sponsored content, no product placement.

Erklärt im Skill skills/lernapps-app/SKILL.md; beurteilt nach dem Punkt der Begutachtung in review/rubric.md.

No request to another server before a click

no-request-before-click · listing, site · error

Bundle fonts, scripts and pictures at build time. Load anything from another server (a video, a map) only after the learner clicks for it.

Erklärt im Skill skills/lernapps-app/SKILL.md.

Collect nothing, set no cookies

no-tracking · listing, site · error

No cookies, no analytics, no tracking pixels, no server that stores data. If the app stores anything, it stays on the device (localStorage) and serves only the app.

Erklärt im Skill skills/lernapps-app/SKILL.md.

Keep the plan file

plan-file · listing · error

Keep .vibe/plan.md from the template, with every section and front matter key. Update phase when you enter a phase. Never edit prePushFailures: the pre-push hook writes it.

Erklärt im Skill skills/lernapps-app/SKILL.md.

Fill the retrospective

retrospective-filled · listing · error

At the end of Commit, fill every part of the retrospective with facts: phases reached, failed checks with rule ids, the creator's turns after the plan, where you had to guess. No names of people.

Erklärt im Skill skills/lernapps-app/SKILL.md.

Runs in the browser, without installation

runs-in-browser · listing · error

The app opens at its URL in a current browser and works there. Nothing to install: no app store, no download, no browser extension.

Stop at the creator's checkpoints

stop-at-checkpoints · listing · error

Stop at each checkpoint (confirm the plan, publish, list) and wait for the creator's answer. Example: "Die App ist fertig und geprüft. Soll ich sie jetzt veröffentlichen?"

Use content of others (texts, pictures, quotes) only with a licence that allows it, and name source and licence next to it.
