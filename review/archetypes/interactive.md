# Review rubric: archetype interactive

One client-rendered app page and a static start page. Judge these items after those of `review/rubric.md`.

## The start page explains the app

```rubric
id: start-page-explains
```

Read the start page and the `<noscript>` text of the app page. The checks only see that they have text. A finding: the
start page does not say what learners train, for whom, and how to begin; or the `<noscript>` text does not say that
the app needs JavaScript and what it does.
