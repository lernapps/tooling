# tooling

Shared tooling for the lernapps.net apps and sites: reusable GitHub workflows, composite actions, `@lernapps/*` packages, the agent skill for building an app, and the fleet audit.

The components here serve the [platform design](https://lernapps.github.io/docs/platform-design/) (agents: skill [`skills/pdt`](https://github.com/lernapps/docs/tree/main/skills/pdt) in lernapps/docs). Planned among them: the thanks and feedback component that creators can include in their apps, counting only explicit clicks, openly and as totals; its own agent skill will live here too.

Nothing here yet. The first content is extracted from the Mathe-Karte, with history kept (lernapps/.github#5). The plan is in [ORGANIZATION.md](https://github.com/lernapps/.github/blob/main/ORGANIZATION.md).
