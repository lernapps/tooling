Before you build a feature, that is anything that is not a fix, read the platform design (pdt42) and the architecture (arc42) in lernapps/docs and place the request in them: the journey and service it serves, and the building block and interface it changes. How to read them is in https://lernapps.net/docs/llms.txt. If the feature changes what the models say, change them with it, in a pull request to lernapps/docs.
